# Q-Lab instructor materials

Q-Lab: AI Pentest Operations is a Bond-inspired, unofficial fan project by Ajmal Shan (0xsh4n). Creator links: [website](https://0xsh4n.github.io) · [Medium](https://0xsh4n.medium.com) · [GitHub](https://github.com/0xsh4n) · [LinkedIn](https://linkedin.com/in/ajmalshan).

The guides are intentionally separate from the student surface. Each guide includes objective, prerequisites, target functionality, discovery path, evidence, impact, remediation, instructor solution, OWASP mapping, and a suggested lecture pairing.

Set `LAB_MODE=vulnerable` for the first pass and `LAB_MODE=secure` for remediation. Set `DEBUG_LAB=true` only while demonstrating model context, retrieval, tool calls, and authorization checks to the class.
